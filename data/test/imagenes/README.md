# Imágenes de prueba

Agregar fotografías con:
- Varios tipos de vehículos.
- Ningún vehículo.
- Vehículos pequeños o lejanos.
- Vehículos parcialmente ocultos.

../expected_counts.csv.

Registrar su origen y condiciones de uso.
