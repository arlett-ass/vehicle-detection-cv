## Atribución

Para cada recurso se debe registrar el enlace de su página original,
el autor y la licencia o permiso aplicable.

La descarga gratuita no implica automáticamente autorización para
redistribuir el archivo. Si se exige atribución, se conservará el
texto indicado por la fuente.
